- [ ] 真實任務比較：以目前專案公開程式／文件的凍結副本，產出可核對的採用／維護資訊；同一本機模型、相同來源與總時間上限，比較一般 pi 原生工具與 CASE。事前固定驗收，不依結果調整；保留完整失敗、耗時、tokens、人介入及工具能力差異。只在隔離測試目錄寫結果，不改產品程式，不向雲端發送本機模型資料。
- [ ] 安裝與發布：完整 kit 測試、獨立審閱、實際隔離 pi 套件安裝／loader／移除、可攜技能安裝後操作、封裝與連結核對。確認遠端 main 未被他人更新後，提交、合併並一般 push，不 force、不刪工作分支或備份。
