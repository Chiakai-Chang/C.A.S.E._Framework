# 目標與交付範圍

更新：2026-09-05。讓使用者透過 pi 等 AI agent，在有限 context 與跨 session／agent 交接後，以合理成本完成符合驗收條件的工作，降低監督、重述與抉擇負擔。

當前交付是完整的 [Workflow Kit](../workflow-kit/README.md)：任務全流程、按需載入與接續、分工整合、證據與驗收、初始化及宿主入口、更新／移除、範本、實例及操作測試。功能對照見 [READINESS](../workflow-kit/docs/READINESS.md)。

舊的「先做 production adapter」與後來「先限縮到 P1 pilot」均已被使用者的完整交付要求取代。M0 規格與證據保留，不作目前套件的可用性前置條件。先交付完整流程，再依使用回饋改善；功能完成不等於已證明模型品質提升。

目標復盤融入實際工作：擴大範圍、增加依賴／角色、反覆修補或交付時，判斷「這一步如何幫助原目標？證據是什麼？繼續或改方法？」只有重大決策改變才簡記。不設排程、不強制角色數或輪數、不為文件小修反覆跑完整測試。

成功以成果正確、必要約束保留、可接續、人的負擔及總成本判斷。測試數、文件量、框架完整度不是使用者價值的替代品。已授權工作自行完成；僅新權限或重要取捨需使用者判斷。

本版本不提供通用 agent runtime、多機同步、強制 sandbox、不可竄改稽核、強身分認證或自動排程。宿主提供模型與工具權限；技能提供工作方法，CLI 提供本地協作紀錄。
